# OS Project

This project is developed as part of the Operating Systems and Systems Programming (OSSP) Project-Based Learning course.

## Week 1 Features

- Interactive REPL loop
- Makefile-based build
- Git repository
- Linux development environment

## Project Structure

```text
osproject/
├── README.md
├── Makefile
├── .gitignore
├── include/
│   └── shell.h
├── src/
│   └── main.c
├── docs/
├── tests/
├── screenshots/
└── bin/
```

## Build

```bash
make
```

## Run

```bash
make run
```

## Clean

```bash
make clean
```
